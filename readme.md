# FIFA World Cup Data Analysis Dashboard

## Project Overview
This project analyzes FIFA World Cup match data using Microsoft Excel. It includes interactive dashboards to understand match results, team performance, goals and player statistics.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Analysis and Visualization

## Key Analysis
- Total matches and total goals
- Home wins, away wins and draws
- Top 10 teams by goals scored
- Goals scored vs goals conceded
- Team possession analysis
- Goals by tournament stage
- Player position analysis
- Referee and card statistics

## Project Objective
To analyze FIFA World Cup statistics and present meaningful insights through interactive Excel dashboards.
